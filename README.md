# Optical Paths

Browser-based optical layout drawing for breadboard-mounted laboratory components.

[中文说明](./README_zh.md) | [English Documentation](./README_en.md)

Try the published app: [Optical Paths on GitHub Pages](https://windsweeps.github.io/Optical-Paths/)

## Highlights

- Draw laboratory optical layouts on common metric breadboards.
- Snap clamp screws to threaded holes with collision-aware automatic clamp rotation.
- Trace source, mirror, lens, and beamsplitter paths.
- Export the current drawing as SVG or PNG after previewing it.
- Switch the interface between Chinese and English.

For setup, usage, WordPress embedding, and implementation notes, open one of the language-specific documents above.
