# Optical Paths：光路图绘制工具

[English Documentation](./README_en.md) | [返回入口页](./README.md)

Optical Paths 是一个在浏览器中运行的光路图绘制工具，面向需要快速整理实验布局的光学实验人员。它使用真实毫米尺寸描述面包板、光学元件、柱子和叉式压板，并根据面包板螺纹孔自动安排固定位置。

在线使用：[https://windsweeps.github.io/Optical-Paths/](https://windsweeps.github.io/Optical-Paths/)

## 当前功能

- 支持五种公制面包板：`900 x 600 mm`、`600 x 600 mm`、`600 x 300 mm`、`450 x 300 mm`、`300 x 300 mm`
- 所有面包板使用 `25 mm` 孔距，首排孔距边缘 `12.5 mm`
- 从元件库选择器添加元件，并在置入前进入悬置预览状态
- 拖动元件后自动寻找压板转角变化最小的可用螺纹孔
- 禁止叉式压板互相重合
- 螺丝被柱子遮挡时允许固定，但会显示警告
- 支持直接输入元件角度
- 支持自定义元件标签，标签保持水平显示
- 支持中英文界面切换，并保存语言偏好
- 支持 SVG 和 PNG 导出预览与本地下载

## 光路规则

当前版本专注于布局和基础光路追迹：

- 光源沿元件角度发射光线
- 输入波长后，光线颜色会随波长改变
- 反射镜按照入射角等于反射角生成反射光线
- 透镜允许光线透射
- 分束立方同时生成透射和反射分支
- 光源位于面包板外时，光线仍会沿真实方向延伸到可见画布边缘

当前尚未实现偏振矩阵和 ABCD 高斯光束计算。

## 内置元件

| 元件 | 类型 | 说明 |
| --- | --- | --- |
| 超稳镜架光线耦合头 | 光源 | 可设置发射角度和波长 |
| 超稳镜架 1 英寸反射镜 | 反射元件 | 按作用面反射光线 |
| 透镜架 | 透射元件 | 允许光线通过 |
| 1 英寸波片架 | 偏振元件 | 当前作为透射元件显示 |
| 1 英寸分束立方 | 分束元件 | `25.4 x 25.4 mm`，对角作用面同时透射和反射 |

## 使用方法

1. 选择面包板尺寸。
2. 点击“添加元件”，从元件库中选择器件。
3. 拖动悬置元件，观察自动匹配的孔位、压板角度和固定状态。
4. 点击“置入”确认位置。
5. 选中元件后，可修改标签、元件角度、压板角度和光源波长。
6. 点击“导出 SVG”或“导出 PNG”，预览后下载图片。

## 本地运行

项目是纯静态网页，不需要安装前端依赖。在项目目录中运行：

```bash
python3 -m http.server 4175
```

然后访问：

```text
http://localhost:4175/
```

## 嵌入 WordPress

推荐先通过 GitHub Pages 托管应用，再使用 WordPress 的 Custom HTML 区块嵌入：

```html
<iframe
  src="https://windsweeps.github.io/Optical-Paths/"
  title="Optical Path Tool"
  style="display:block;width:100%;height:calc(100vh - 40px);min-height:820px;border:0;"
></iframe>
```

如果页面模板限制正文宽度，可将 Custom HTML 区块放入全宽 Group 区块，或为绘图页创建只保留 Post Content 的全宽模板。

## 设计边界

- 不提供账号登录
- 不提供云同步
- 不提供多人协作
- 不是机械 CAD 软件，不用于生成加工图纸
- 当前仅提供基础二维布局和光路示意
